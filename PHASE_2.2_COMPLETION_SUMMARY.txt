ARCHITECTURE HIGHLIGHTS
================================================================================

Price Calculation Algorithm:
  - Rule-based system with priority ordering
  - 5 rule types: fixed, percentage, demand_based, competitor_based, time_based
  - Demand-based adjustments: -20% (low) to +15% (high)
  - Time-based adjustments: +5% (peak), +3% (weekend)
  - Min/max price bounds enforcement

Authorization Model:
  - Read endpoints: All authenticated users (employee+)
  - Write endpoints: Managers and admins only
  - Store scope: Users see only their stores' pricing

Data Flow:
  pricing_rules (strategy) + demand_metrics (data) → calculateRecommendedPrice()
  → recommendedPrice + pricing_history (audit)
